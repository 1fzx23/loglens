功能亮点

格式自动识别

自动识别 Nginx/Apache 访问日志、syslog、常见应用日志（ISO 时间戳），识别不了就回退纯文本，也可 --format 强制指定。

错误模式聚类

把消息里的数字、IP、UUID、路径归一化成占位符，散落的同类错误自动合并，附带出现次数与时间跨度。

多维统计与过滤

级别/状态码/Top IP/请求路径分布 + 时间线；按级别、时间范围、关键字、正则过滤，支持 stdin 管道。

三种报告输出

自包含 HTML 报告（内嵌 SVG 图表、无 JS）、Markdown、JSON——最后一种可直接喂给脚本或 AI 工作流。

快速开始

安装

git clone https://github.com/1fzx23/loglens.git
cd loglens
python loglens.py --help

常用命令

# 统计 nginx 访问日志（级别/状态码/Top IP/时间线）
python loglens.py stats access.log

# 错误聚类：同类错误合并计数
python loglens.py errors app.log --top 20

# 过滤今晚 22 点以后的 ERROR/CRITICAL
python loglens.py filter app.log --level ERROR,CRITICAL --since "2026-10-11T22:00"

# 管道 stdin
cat error.log | python loglens.py errors -

# 生成自包含 HTML 报告
python loglens.py report access.log

错误聚类效果

3 条不同订单号、不同端口的超时报错，被合并成 1 个模式：

[1] ×4      ERROR            10-11 09:02~10-11 09:05
    orders Order <N> failed: TimeoutError after <N>s connecting to payment-gw:<N>

变量归一化为 <N> / <IP> / <UUID> / <PATH>，一眼定位高频问题。

技术栈

  • Python 3.9+
  • 零外部依赖（仅标准库：re、argparse、json、datetime 等）
  • 手工解析 nginx 时间，无 locale 陷阱；时区友好
  • 支持 Windows / macOS / Linux
